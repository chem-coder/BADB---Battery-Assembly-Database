## 3. Оценка объёма по 6 документам ЕСПД

### 3.1. Техническое задание (ГОСТ 19.201-78)

**Структура по ГОСТ** (типовые разделы):
- Введение (наименование, основание, область применения)
- Назначение разработки
- Требования к программе (функциональные, технические, к видам обеспечения)
- Требования к программной документации
- Технико-экономические показатели (опционально, для внутреннего — часто опускают)
- Стадии и этапы разработки (задним числом по git log)
- Порядок контроля и приёмки

**Откуда брать:**
- Назначение + область применения → старая `Концепт.md` + `BADB_APP_PROJECT_MAP.md` Дали
- Функциональные требования → пункты 1.1-1.9 из этой карты
- Требования к безопасности → 1.1 + 1.5
- Требования к интеграции → 1.5 (контракты), 1.8 (инфраструктура)
- Порядок приёмки → отсылка к документу 3.6 (Программа и методика испытаний)

**Оценка:** ~25-40 страниц. **2-3 дня.**
