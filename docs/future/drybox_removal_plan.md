## Что уходит

1. **Vue `TapeDryBoxPanel`**: кнопки «поместить/извлечь/вернуть», параметры
   шкафа (T/атмосфера/прочее), гейт по финальной сушке. **Остаётся:**
   «Лента израсходована» (deplete — отдельная сущность, живёт) и НОВОЕ
   свободное поле заметок «Хранение» (см. ниже).
2. **Бэкенд-гейты**:
   - `tapeDryBoxService`: `has_final_dry_box_storage` (зависимость от
     `drying_pressed_tape.ended_at`) — гейт удаляется; place/remove/return
     роуты остаются в API как deprecated (vanilla ещё зовёт их до
     отключения), но перестают проверять предусловия.
   - `electrodeCutBatchService` (~строка 335): создание партии вырубки
     автоматически «кладёт ленту в шкаф» (INSERT в `tape_dry_box_state` с
     COALESCE из финальной сушки) — эта связка удаляется целиком.
3. **Vanilla 2-electrodes «Что дальше с лентой?»** — блок остаётся как есть
   (vanilla уходит на пенсию, не трогаем).

## Что приходит вместо

- Поле **«Хранение (заметки)»** на ленте: свободный текст с плейсхолдером
  «напр.: вынута из шкафа на 30 мин 30.07, вернула И.И.». Хранение: либо
  (а) в существующем `tapes.notes` без миграции, либо (б) отдельная колонка
  `tapes.storage_notes` (d056+, одна строка ALTER). **Рекомендую (б)** —
  не смешивать с общими примечаниями ленты.

## Что НЕ трогаем (данные)

- Таблица `tape_dry_box_state` и колонка `availability_status` остаются в
  БД (forward-only): исторические данные читаемы, `depleted` продолжает
  работать как статус списания.
- `availability_status` упрощается в UI до двух значений: «активна» /
  «израсходована» (значения `in_dry_box`/`out_of_dry_box` в списках
  показываются как «активна»).

## Порядок работ (после «го»)

1. Миграция dNNN: `tapes.storage_notes text` (если вариант «б»).
2. Vue: `TapeDryBoxPanel` → простая карточка «Хранение» (deplete + заметки).
3. Бэкенд: снять гейт в dry-box роутах; удалить авто-INSERT из
   `electrodeCutBatchService`; тест на «вырубка не трогает dry-box».
4. Списки/фильтры Vue: availability_status → активна/израсходована.
5. Доки: tapes.md, PARITY.md.
