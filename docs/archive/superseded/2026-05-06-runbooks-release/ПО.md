Для установки и запуска данного приложения (Node + Express + PostgreSQL + vanilla JS) на компьютере с Windows потребуется следующее.

PostgreSQL (рекомендуется версия 16)

Установить PostgreSQL 16 с официального сайта postgresql.org (Windows-инсталлятор).

Во время установки:

Можно установить pgAdmin (необязательно, но удобно для администрирования).

Задать пароль для пользователя postgres (сохранить его).

Порт 5432 оставить по умолчанию.

Если после установки PostgreSQL откроется Stack Builder с предложением установить дополнительные пакеты — ничего выбирать не нужно, можно закрыть окно. Для работы приложения дополнительные компоненты не требуются.

Node.js (версия LTS)

Установить Node.js LTS (рекомендуется 18.x или 20.x).

Устанавливаются:

node

npm

Проверка после установки:

node -v

npm -v
